*monospace.txt*  Monospace colorschemes for Neovim

Monospace provides seven colorschemes ported from the Monospace themes for
Visual Studio Code. Neovim 0.10+ is required.

Use one of these commands in your config or at the command line: >
    colorscheme monospace
    colorscheme monospace-light
    colorscheme space
    colorscheme space-light
    colorscheme idx-monospace
    colorscheme idx-monospace-light
    colorscheme idx-monospace-flat
<
No setup call is required.

The colorschemes set terminal colors and include Neovim, Tree-sitter, LSP,
diagnostic, and optional plugin highlights. See the README for the supported
plugins and installation examples.

For lualine, use any of the colorscheme names as the theme.
Palette tables are available at `require("monospace").palettes`.
